# NoteSphere

A full-stack note-taking app built with Next.js and TypeScript, built to learn and apply the Next.js App Router in a real, complete project.

## About

NoteSphere lets users create, edit, and organize their notes in one place. It was built as a hands-on project to go deeper into Next.js — moving from tutorials to a real, working application with actual data persistence and UI polish.

## Features

- 📝 **Create, edit, and delete notes** with a clean, responsive interface
- 🗂️ **Organize notes** into folders/tags/categories for easy retrieval
- 🔍 **Search** across notes to quickly find what you need

## Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** CSS
